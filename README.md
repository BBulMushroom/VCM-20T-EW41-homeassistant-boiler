# EW41 Boiler

EW41 TCP로 보일러를 제어하는 Home Assistant 통합입니다.
VCM-20T / NRM-20S에서 확인했습니다. 별도 서버나 MQTT가 필요하지 않습니다.

## 기능

- 거실·방1·방2·방3 온도 설정과 난방 ON/OFF
- 전체방 난방 ON/OFF
- 메인 운전모드: 난방+온수 / 온수전용
- 방별 본체 예약과 HA 반복난방
- 상태 새로고침과 RAW 진단

## 설치

Home Assistant Core 2025.6 이상, HACS가 필요합니다.

1. HACS → ⋮ → 사용자 지정 저장소에 아래 주소를 **Integration**으로 추가합니다.
   ```text
   https://github.com/BBulMushroom/VCM-20T-EW41-homeassistant-boiler
   ```
2. **EW41 Boiler**를 다운로드하고 HA를 재시작합니다.
3. 설정 → 기기 및 서비스 → 통합 구성요소 추가 → **EW41 Boiler**를 선택합니다.
4. EW41 IP와 포트를 입력합니다. 기본값: `192.168.0.22:8899`.

기본 설정: 응답 대기 2초, 상태 조회 10초, 온도 10~30℃·0.5℃ 단위.
온도 범위는 조절기에 맞춰 통합 옵션에서 변경하세요.

수동 설치: `custom_components/ew41_boiler`를 HA의 `/config/custom_components/ew41_boiler`에 복사하고 재시작합니다.

## 예약난방

| 방식 | 시간 설정 | 제어 |
|---|---|---|
| 본체 예약 | 벽 조절기 | HA에서 켜기/끄기 |
| HA 반복난방 | HA | 주기·가동 시간 설정 |

**HA 반복난방 설정**

1. 방마다 토글, 날짜+시간 도우미를 만듭니다. 토글은 OFF로 둡니다.
2. [반복난방 블루프린트](https://github.com/BBulMushroom/VCM-20T-EW41-homeassistant-boiler/blob/main/blueprints/automation/ew41_boiler/repeat_heating.yaml)를 가져옵니다.
3. 자동화를 만들고 같은 방의 온도조절기·본체 예약·도우미를 연결합니다.
4. 주기와 가동 시간을 설정합니다. 기본값: **2시간마다 10분**.

대시보드에서 시간을 바꾸려면 숫자 도우미 2개를 연결하세요.
주기: 1~24시간, 가동 시간: 1~59분. 각각 1시간·1분 단위입니다.
연결한 도우미 값이 자동화의 고정값보다 우선합니다.

주기는 가동 시작부터 다음 시작까지입니다. 2시간/10분이면 10분 난방 후 110분 쉽니다.
켜면 즉시 시작하고, 끄면 난방을 종료합니다. 본체 예약은 자동 해제됩니다.

## 사용 시 참고

- 수동 제어·자동화 해제 전 HA 반복난방을 끄세요.
- HA 정지·통신 장애 시 반복난방의 자동 종료가 안 됩니다.
- HA 반복난방은 본체 예약과 동작이 다를 수 있습니다.
- 본체 예약을 끄면 해당 방은 일반 난방으로 돌아갑니다.
- 난방+온수로 복귀하면 거실 난방이 켜집니다.

문제 발생 시 설정 → 시스템 → 로그에서 `ew41_boiler`를 확인하세요.
패킷과 API는 [개발 문서](docs/protocol.md)를 참고하세요.
